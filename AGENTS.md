# NEBULITH Project Instructions

## Project context

NEBULITH is an AI-powered developer workspace featuring GitHub repository analytics, intelligent AI code reviews, bug and vulnerability detection, and developer productivity insights.

## Technology stack

- Frontend: React, Vite, and Tailwind CSS
- Backend: Node.js and Express
- Database: MongoDB Atlas with Mongoose
- Planned integrations: GitHub API and an AI API

## Development rules

1. Preserve the existing project structure and working code.
2. Use a clean, modular, maintainable architecture.
3. Keep frontend and backend responsibilities separate.
4. Never expose API keys, passwords, database credentials, or other secrets.
5. Store secrets in environment variables.
6. Validate inputs and handle errors properly.
7. Enforce authorization on the server for protected operations.
8. Build reusable React components.
9. Avoid unnecessary dependencies.
10. Test important changes before declaring them complete.
11. Explain significant changes and list modified files.
12. Ask for approval before destructive operations, major architectural changes, or installing new dependencies.
13. Do not claim a feature works unless it has been tested.
